# Data-Analytics-and-visualisations
DAV lab programs by Moksh

Open `experiment 1.ipynb` through `experiment 11.ipynb` in GitHub Preview to see saved outputs beneath the code cells, including tables and plots. Import and assignment cells may have no visible output.

To rerun locally, install `jupyter numpy pandas matplotlib seaborn scipy scikit-learn` and choose **Run All** in Jupyter. Experiment 3 uses the bundled synthetic sample data in `students.csv`; replace it with your own dataset using the same columns as needed.
